## How to Report Unauthorized Access to GitHub

If you believe your GitHub account or device was accessed without authorization, take these steps:

### Step 1 — Secure Your Account Immediately

1. **Change your GitHub password** at https://github.com/settings/security
2. **Review and revoke active sessions** at https://github.com/settings/sessions
3. **Review authorized OAuth apps** at https://github.com/settings/applications
4. **Review personal access tokens** at https://github.com/settings/tokens — revoke any you do not recognize
5. **Enable two-factor authentication** (if not already enabled) at https://github.com/settings/security

### Step 2 — Review Your Account Activity

1. **Security log:** https://github.com/settings/security-log — shows login events, token usage, and permission changes
2. **Audit every repository** you own for unexpected commits, branches, or collaborators

### Step 3 — Contact GitHub Support

- **GitHub Support form (recommended):** https://support.github.com/contact/account-security
- **Select "Account security"** as the category
- Include:
  - Your GitHub username
  - The specific date you believe unauthorized access occurred
  - Description of suspicious activity (unexpected code changes, unknown sessions, etc.)
  - Screenshots of any evidence

### Step 4 — Secure Your Local Device

Since the concern involves GitHub Desktop and VS Code on your local machine:

1. Run a full antivirus/malware scan
2. Check for unknown VS Code extensions — open VS Code → Extensions panel → review all installed extensions
3. Review GitHub Desktop settings → check linked accounts and repositories
4. Check your device for unknown applications or startup programs
